How it works

From one sentence to one clean commit.

Arbiter asks only the questions that matter, then does the tedious parts itself.

Describe the outcome

Type what you want and @ the projects involved. A local model sizes the work and asks a clarifying question only when a choice is really yours.

Agents work in parallel

Bigger jobs become a plan you approve. Steps run side by side in isolated worktrees, hand their interfaces to each other, and heal their own failing checks.

Review, then publish

See your app running, read the diff and leave comments. Publish as one commit with a written message, as a draft pull request or to a local branch.

Features

Everything around the agent, handled.

Plans with dependencies

Steps, scopes and acceptance checks you can edit before anything runs. Steps that depend on others simply wait.

Self-healing runs

Crashes, stalls and rate limits are resumed or rerouted. Failing tests come back to the agent as short excerpts, never raw logs.

Token discipline

Deterministic fixes first. A local model handles triage, reviews, research and commit messages, so frontier agents get only what they need.

See your app

The app starts by itself after a change. Point at an element in the preview and ask for a change right there.

Across repositories

One feature can span a data pipeline and the app that reads it. Each project gets its own branch and its own commit.

Terminal and editor

A real terminal in each task's copy and a code editor for quick fixes. Open them with Ctrl+J.

Privacy

Your code, your subscriptions, your memory.

Arbiter runs on your computer and talks only to the coding tools you signed in to.

  • ✓No token proxy. You sign in to Claude Code or Codex yourself. Paid usage stays off unless you turn it on.
  • ✓Nothing spills into shared repos. Notes, guidance and history live in your own private memory repository.
  • ✓Local research. Web lookups run on your machine. Anything from a signed-in site is checked locally before an agent sees it.
  • ✓You approve every push. Arbiter's working branches never leave your computer, and it never force-pushes.

FAQ

Questions

Is Arbiter free?

Yes. Arbiter is free and open source under the MIT license. You use your own Claude Code or Codex subscription; Arbiter adds no fees and never resells tokens.

Which agents does it work with?

Claude Code and Codex, installed and signed in on your computer, plus local models for smaller jobs such as triage, reviews, research and commit messages.

Which platforms are supported?

Windows today. macOS and Linux build from the same code and will get installers soon.

Will it change my repository behind my back?

No. Every task works in its own copy on an Arbiter branch that stays on your computer. Your checkout changes only when you commit or publish, and every push asks first.

How do updates work?

Arbiter checks for new releases, downloads them in the background and installs them when you close it, or right away from the banner. Every update is verified against a signing key built into the app.

Windows warns me when I run the installer. Why?

Early builds are not code-signed yet, so SmartScreen does not recognise them. Choose More info, then Run anyway. You can also build the app from source.
